Import tasks (TSV)

Paste tab-separated rows. A header with Title imports tasks; a header with Description + Amount imports cost entries (columns: ID, Date, Description, Amount, Epic, Contractor, Notes). For tasks the header must contain at least Title; recognized columns (any order): ID, Title, Status, Room, Contractor, Cost Estimate, Cost Actual, Due Date, Priority, Notes, Epic, Depends On (comma-separated task IDs), Assignee, Title EN, Notes EN. On updates, only the pasted columns change. Missing IDs and timestamps are generated; rows whose ID already exists update that task in place.
