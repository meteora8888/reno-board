Import tasks (TSV)

Paste tab-separated rows. The first row must be a header containing at least Title; recognized columns (any order): ID, Title, Status, Room, Contractor, Cost Estimate, Cost Actual, Due Date, Priority, Notes, Epic, Depends On (comma-separated task IDs). Missing IDs and timestamps are generated; rows whose ID already exists update that task in place.
